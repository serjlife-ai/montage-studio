## Девять правил контура

1. **Порог тишины считается из файла.** Константа однажды вырезала 46 секунд речи.
   Никогда не зашивать число, не посмотрев на гистограмму уровней.
2. **Инвариант вместо надежды.** Сборка обязана падать на браке, а не выдавать его.
   Два инварианта уже стоят: порог и верстка титров. Снимать нельзя.
3. **Сдача с числами.** Хронометраж, катов, слов до/после, разрыв уровней.
   «Вроде нормально» - не отчёт.
4. **Механика - агенту, смысл - человеку.** Резка тишины, титры, уровни, формат -
   автоматика. Что выбросить по содержанию - решает автор ролика.
5. **Смотреть кадры перед сдачей.** Минимум 8 точек по длине ролика, глазами.
6. **Исходники не трогаем.** Работа только в копиях, оригинал остаётся нетронутым.
7. **Сначала режем, потом одеваем.** ffmpeg-контур доводит монтаж до финала,
   и только потом HyperFrames кладёт графику. Обратный порядок = переделка
   графики после каждой правки.
8. **Звуки только из банка, свой синтез запрещён.** Источник - библиотека
   `media-use` (Pixabay License). Проверка звука - рендером с ЗАГЛУШЕННЫМ
   голосом, остальные метрики врут. Подробно: [[knowledge/sound-design]].
9. **Хук - вариация подтверждённого донора, а не выдумка.** Подробно: [[knowledge/hooks]].

## Две руки монтажёра

| Движок | Для чего | Точка входа |
|---|---|---|
| **ffmpeg-контур** | реальная съёмка: резать, чистить, склеивать, мерить | `tools/reel.py` - эталон, одна команда на весь ролик; `tools/reels.py` - базовый цикл |
| **HyperFrames** | поверх съёмки: графика, кинетические титры, плашки, моушн | скилл `hyperframes` |

**Закон порядка: сначала режем, потом одеваем.**
Точка входа в графику всегда одна - скилл `hyperframes`, он сам подберёт воркфлоу.
Дёргать подскиллы напрямую не надо.

```
│   ├── dynamic-carousel.md    ← карусель Instagram: закон двух слоёв

│   └── capabilities.md        ← карта умений и границ
├── tools/                     ← рабочий код
│   ├── reel.py                ← ЭТАЛОН: весь ролик одной командой по плану
│   ├── reels.py               ← базовый цикл: резка → уровни → титры → отчёт
│   ├── subtitles.py           ← титры поверх готового видео
│   ├── dynamic.py             ← каты с зумом и свушами, когда пауз нет
│   ├── window.py              ← голова в окошко, место под текст
│   ├── creative.py            ← всплывашки, чек-листы, флеши
│   ├── accents.py             ← число-шильдик и карточка призыва
│   ├── occlude.py             ← текст уходит ЗА персонажа
│   ├── ambience.py            ← раскладка звуков по таймлайну
│   ├── sfx_bank.py            ← сборка банка звуков из библиотеки media-use
│   ├── carousel.py            ← нарезка панорамы на слайды карусели
│   ├── slide.py               ← верстка слайда: текст нашим шрифтом
│   └── README.md              ← как запускается каждый инструмент
├── sfx/                       ← готовый банк звуков wav, отобраны по замеру
├── models/                    ← сюда качается модель whisper (в архиве её нет)
└── .agents/skills/            ← 26 скиллов HyperFrames (Apache-2.0)
```

**Состав кода и правила связаны.** `reel.py` не работает в одиночку: он тянет
`reels`, `subtitles`, `creative`, `window` и запускает `dynamic.py`. Поэтому
сборка пакета падает, если правила ссылаются на инструмент, которого внутри нет.

Готовые ролики в папке контура не храним - отдаём файлом и убираем.

## Границы

- Монтажёр не слышит звук и не смотрит видео. Судит по числам и по вытащенным кадрам.
  Смешно / попадает ли ритм / живая ли энергия - решает автор.
- Что вырезать по смыслу - решает автор. Монтажёр предлагает схему по транскрипту.
- Трендовое аудио Instagram накладывается только в приложении, не файлом.
- Публикация - не зона монтажёра. Отдаётся файл.
