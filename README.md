# Монтажная студия для Claude

Папка, в которой Claude монтирует твои ролики: режет паузы, ставит титры,
выравнивает звук, кладёт графику и звуковые эффекты. Всё считается на твоём
компьютере - ни подписок, ни облака, ни ключей, ни лимитов на минуты.

Забирай бесплатно. Собрано в [ИИ Империи](https://aiimperia.ru).

---

## Что это на самом деле

Не приложение с кнопками. Это **правила, инструменты и память**, которые
превращают Claude Code в монтажёра. Ты пишешь словами:

> Смонтируй ролик из ~/Downloads/IMG_1234.mov. Убери паузы, поставь титры,
> выровняй звук. Мат в титрах закрой звёздочками.

И получаешь файл плюс отчёт с числами: сколько было, сколько стало, сколько
катов, сколько слов до и после. Не «вроде нормально», а цифры.

**Главное отличие от онлайн-сервисов:** контур падает на браке, а не отдаёт его.
Если под нож попала живая речь - сборка останавливается сама и говорит почему.
Этот инвариант стоит после реального случая: константа порога однажды вырезала
46 секунд речи, и никто бы не заметил.

## Что умеет

| | |
|---|---|
| **Проверка исходника** | меряет файл до монтажа: уровни, тишина, кадр, два ли источника звука |
| **Резка** | паузы и запинки по гистограмме файла, а не по константе |
| **Титры** | word-by-word, верстка меряется в пикселях, цензура мата по корням |
| **Звук** | выравнивание двух источников компандером, банк SFX, замер эффектов рендером без голоса |
| **Динамика** | каты с микро-зумом и свушами, когда человек говорит без пауз |
| **Кадр** | вертикаль 1080x1920, safe zone, голова в окно - место под текст |
| **Графика** | 26 скиллов HyperFrames: кинетическая типографика, плашки, титры за силуэтом |
| **Карусели** | панорама на два слайда, оживление кадра, проверка перед загрузкой |
| **Оценка перед сдачей** | считает, не вышла ли неподвижная говорящая голова |
| **Чекпоинты** | долгая работа переживает обрыв сессии |

## Что нужно

**macOS или Linux**, Claude Code с подпиской Claude, немного места на диске.
Всё остальное ставит сам Claude: ffmpeg, whisper, node, шрифты, модель
распознавания.

## Как поставить

**Если ты пришёл из личного кабинета ИИ Империи** - у тебя уже есть промпт,
просто вставь его в Claude Code. Он всё сделает сам.

Если пришёл со стороны:

1. Скачай эту папку: `git clone` или кнопкой **Code → Download ZIP**.
2. Открой в ней Claude Code.
3. Отправь одну фразу:

> Разверни монтажный контур по SETUP.md. Поставь всё что нужно, проверь на моём
> файле и объясни простым языком, что получилось.

Дальше он сам. Один шаг придётся сделать руками - установку Homebrew, если его
нет: она просит пароль от компьютера, и Claude его не увидит.

Подробная инструкция человеческим языком - в [НАЧНИ-ОТСЮДА.md](НАЧНИ-ОТСЮДА.md).
Готовые формулировки задач - в [ПРОМПТЫ.md](ПРОМПТЫ.md).

## Что внутри

```
CLAUDE.md          правила контура, Claude читает их сам
agents/editor/     устав монтажёра: шестнадцать законов
knowledge/         память: формат, звук, хуки, графика, границы
tools/             код монтажа: сборка, титры, зумы, окно, карусели
sfx/               банк звуков, отобраны замером, а не на слух
.agents/skills/    26 скиллов графики HyperFrames (Apache-2.0)
```

## Границы - честно

- **Монтажёр не слышит звук и не смотрит видео.** Он судит по числам и по
  вытащенным кадрам. Смешно или не смешно, попадает ли ритм - решаешь ты.
- **Что вырезать по смыслу - твоё решение.** Он уберёт паузы и брак, но не
  решит, какая шутка лишняя.
- **Трендовое аудио Instagram** накладывается только в самом приложении.
- **Контур собирает вертикаль.** Горизонтальный исходник он не кропнет молча -
  скажет и предложит перегнать.
