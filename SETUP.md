# Установка контура (инструкция для Claude)

> Claude, это твоя рабочая инструкция. Разверни контур на этой машине,
> проверь результат числами и доложи человеку простым языком.
> Машина: macOS. Всё локальное, ключей и подписок на сервисы не требуется.

---

## Порядок

### Шаг 1. Запусти скрипт

```bash
./setup.sh
```

Он делает шесть вещей и печатает чеклист:

1. проверяет Homebrew;
2. ставит `ffmpeg`, `whisper-cpp`, `node`, если их нет;
3. проверяет `numpy` и `pillow` в python3, при отсутствии собирает `.venv` рядом;
4. качает модель распознавания речи `ggml-large-v3-turbo.bin` (1.6 ГБ) в `models/`;
5. подключает скиллы графики: симлинки `.claude/skills/*` → `.agents/skills/*`;
6. проверяет банк звуков в `sfx/` и собирает заново, если пусто.

В конце появляются две команды-обёртки: `./montage` (базовый цикл резки и титров)
и `./reel` (эталонная сборка целиком по плану).

### Шаг 2. Разбери незакрытые пункты

Скрипт выходит с кодом 1, если что-то не встало. Разбирай сам, не перекладывай на человека:

| Строка «НЕТ» | Что делать |
|---|---|
| Homebrew не установлен | это единственный шаг человека - он просит пароль. Дай команду из вывода и подожди |
| ffmpeg / whisper-cli / node | `brew install ffmpeg whisper-cpp node` |
| numpy / pillow | скрипт сам соберёт `.venv`; если упал - `python3 -m venv .venv && .venv/bin/pip install numpy pillow` |
| модель не скачалась | повтори `./setup.sh`; при плохой связи качай докачкой: `curl -C - -L -o models/ggml-large-v3-turbo.bin <URL из setup.sh>` |
| банк звуков пуст | `python3 tools/sfx_bank.py sfx` - нужен ffmpeg и папка `.agents/skills/media-use` |

### Шаг 3. Проверь на живом файле

Возьми у человека любое видео и прогони **сначала анализ, без рендера**:

```bash
./montage видео.mov --analyze
```

Ожидаемый вывод - три строки: полка / порог, каты и хронометраж, инвариант.
Если порог получился выше самого тихого говорящего, ролик потеряет речь -
читай `knowledge/audio-two-sources.md` до того, как рендерить.

Полная сборка:

```bash
./montage видео.mov -o готово.mp4 --censor
```

Приёмка сборки - по числам из отчёта:

- **слов до и после**: расхождение больше 1% = речь пострадала, не отдавать;
- **громчайший вырезанный кадр** обязан быть ниже порога;
- **катов и хронометраж** - сверить с ожиданием.

Эталонная сборка целиком (порядок слоёв зафиксирован, читай `knowledge/reel-canon.md`):

```bash
./reel видео.mov --plan план.json --dry     # сначала разбор и план, без рендера
./reel видео.mov --plan план.json -o готово.mp4
```

Потом вытащи 8-9 кадров по длине ролика и посмотри на них глазами:

```bash
ffmpeg -y -v error -i готово.mp4 -vf "fps=1/20,scale=360:-1" кадр_%02d.png
```

### Шаг 4. Проверь второй движок (графика)

```bash
npx hyperframes doctor
```

Зелёный доктор значит: Chrome-headless, ffmpeg и распознавание речи движок видит.
Первый запуск скачает пакет - это нормально, ключей он не просит.

### Шаг 5. Доложи человеку

Коротко и без терминов: что встало, что не встало, что проверено на живом файле,
какая команда монтирует ролик. Числа приложи.

## Чего делать НЕ надо

- Не ставить Kokoro TTS и MusicGen: они тянут torch на несколько гигабайт.
  Озвучка и музыка берутся генерацией или готовыми файлами.
- Не ставить Remotion: HyperFrames закрывает те же задачи.
- Не менять пороги и константы в `tools/` «чтобы получилось короче» -
  инварианты там стоят после реальных дефектов.
- Не трогать оригиналы съёмки. Работать только с копиями.

## Если что-то пошло не так

| Симптом | Причина и лечение |
|---|---|
| `whisper-cli: command not found` | `brew install whisper-cpp` |
| `модель whisper не найдена` | нет файла в `models/` - перезапусти `./setup.sh` |
| `шрифт не найден` | редкая сборка macOS. Задай свой: `SUBS_FONT=/System/Library/Fonts/HelveticaNeue.ttc ./montage ...` |
| `AssertionError` про порог | под нож попала речь. Это защита, а не поломка: смотри `knowledge/audio-two-sources.md` и задай порог вручную `--threshold` |
| `AssertionError` про верстку | фраза титров не влезает в кадр. Уменьшить `MAX_WORDS` в `tools/subtitles.py` |
| ffmpeg ругается на кодек | исходник в экзотическом формате: перегони `ffmpeg -i вход -c:v libx264 -c:a aac перегон.mp4` |
| `кадр 1920x1080, а контур собирает вертикаль` | исходник горизонтальный. Команда перегона напечатана в самой ошибке - выполни её и повтори |
| видео легло набок | iPhone пишет вертикаль с матрицей поворота, смотри реальный кадр, а не `ffprobe` |
