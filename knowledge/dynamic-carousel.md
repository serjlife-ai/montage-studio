# Динамичная карусель Instagram

> Карусель, где картинка живёт, а текст стоит намертво. Разобрано с поста @beautymaster (18.08.2026), собрано под наш контур.

## Что это физически

Карусель Instagram принимает смешанный комплект: часть слайдов - картинки, часть - короткие MP4. Эффект «оживления» даёт не 3D, а дисциплина кадра:

- камера статична,
- фон статичен,
- текст статичен,
- двигается ровно **один** объект.

Мозг читает это как объём. Стоит начать двигать второй объект или камеру - эффект рассыпается в обычное видео.

Второй приём - **бесшовная панорама**: один широкий макет режется на первые два слайда. При листании сцена продолжается за край экрана. Это и удерживает палец на втором свайпе.

## Порядок сборки

**1. Панорамный макет.** Генерим один широкий кадр под N слайдов: для двух слайдов 3:4 это 3:2 (например 2160x1440). Персонаж на левой половине, продолжение тела и объекты - на правой.

**2. Нарезка.** Одна команда, шов пиксель в пиксель:

```bash
python3 tools/carousel.py slice панорама.png --slides 2
```

**3. Оживление - ПОСЛЕ нарезки, не до.** Гоним через image-to-video (Seedance / Kling / Veo, скилл `higgsfield-generate`) уже готовый вертикальный слайд. Промпт ниже. Длина 4-6 секунд, зацикливаемая.

Почему такой порядок: широкую панораму модель возвращает высотой около 1024 и меньше, после разреза половина выходит ~540 пикселей по ширине - мыло. Вертикальный слайд 3:4 близок к 9:16, модели отдают его в полный рост.

Синхронность движения между слайдами не нужна: слайды никогда не видны одновременно, стык держит статичная картинка, а не такт пульсации.

Оживлять достаточно **первый слайд** - он решает, будет свайп или нет. Резать видео инструмент умеет, но это оправдано только ради движения, непрерывно идущего через границу слайдов, и стоит потери резкости.

**4. Наложение текста.** См. закон двух слоёв ниже.

**4a. Кадр из GPT Image.** GPT Image не умеет 3:4, отдаёт 1024x1536 (2:3). Приводим к слайду тем же инструментом:

```bash
python3 tools/carousel.py slice кадр.png --slides 1
```

Срезается около 11% по вертикали, поэтому в промпте закладываем запас: весь текст в центральных 80% высоты.

**5. Проверка комплекта до загрузки:**

```bash
python3 tools/carousel.py check слайд1.png слайд2.mp4 слайд3.png
```

Ловит разъезд соотношений (Instagram обрежет все слайды по первому), выход за лимиты ленты, ширину меньше 1080, видео длиннее 60 секунд. Выход 1 - не грузить.

## Закон двух слоёв

**Текст не отдаём image-to-video модели.** Половина чужих промптов - это мольба к нейросети не портить буквы (`DO NOT TOUCH THE TEXT`, `treat the text as a fixed static layer`). Кириллицу модели плывут регулярно, а перегенерация стоит кредитов и времени.

Правильный порядок:

1. генерим и оживляем **чистый визуал без текста**,
2. текст кладём сверху `tools/slide.py` по JSON-плану.

Что это даёт: шрифт ровно тот, что нужно; правка формулировки не требует перегенерации видео; текст читается на любом устройстве. Модель отвечает только за то, что умеет - за движение.

Исключение: если текст должен быть частью сцены (лежит на поверхности, отражается, гнётся) - тогда он идёт в макет и запреты из промпта обязательны.

## Промпт на оживление

Скелет, который работает. Первый блок - запреты, они важнее описания движения.

```
Static camera. Keep the entire composition fully locked.
The background must remain completely static.
Preserve the appearance, color and size of the object.
Do not add new elements, letters, symbols or interface elements.

Moving: <что именно двигается и как>
Everything else in the frame stays 100% unchanged.
```

Если текст всё же в макете, добавить блок:

```
The text must remain absolutely still. Do not move the text or icons.
All text, letters, arrows, icons must stay 100% unchanged.
Do not animate, shift, distort, replace or regenerate any text.
Treat the text as a fixed static layer.
```

В строке `Moving:` - один объект и одно-два действия. «Хамелеон моргает и высовывает язык» работает. «Хамелеон идёт по стене, бабочки летают, ветер в листве» - нет.

## Длина и зацикленность

**5 секунд.** Слайд смотрят 1-3 секунды, первый чуть дольше. Движение должно
прочитаться примерно за полторы секунды, дальше идёт повтор. Лимит слайда 60
секунд, но длинный ролик бессмысленен: свайпнут раньше, чем досмотрят.

**Цикл делается на монтаже, а не промптом.** Instagram крутит видео-слайд по
кругу сам, но модель не гарантирует совпадение последнего кадра с первым - на
стыке рывок. Просьба `seamless loop` в промпте почти не работает: модель занята
удержанием статики.

```bash
python3 tools/carousel.py loop база.mp4 -o слайд1_цикл.mp4
```

Пинг-понг (по умолчанию) склеивает прямой ход с обратным - стык гладкий всегда,
длина удваивается. Для направленного движения, которое в реверсе выглядит
неестественно (бегущие частицы, полоса развёртки), берётся `--mode crossfade`.

Замер на проверке: разрыв между последним и первым кадром 125.1 из 255 стал 0.6
у пинг-понга и 5.2 у растворения.

Отсюда правило выбора движения: **бери то, что циклично само** - пульсация
яркости, моргание, дыхание. Тогда и реверс не читается как отмотка назад.

## Что оживлять

Живое движение читается, когда оно мелкое и повторяющееся:

- моргание, движение зрачка, дыхание,
- пульсация свечения, бегущие частицы под поверхностью,
- медленное вращение одного элемента,
- мерцание экрана, полоса развёртки,
- пар, дым, рябь воды.

Не работает: проходы персонажа, повороты головы, любое движение камеры. Модель начинает перерисовывать сцену и ломает совпадение с соседним статичным слайдом.

## Технические рамки

| Параметр | Значение |
|---|---|
| Соотношение слайда | 3:4 (1080x1440) или 4:5 (1080x1350), **одинаковое у всех слайдов** |
| Панорама на 2 слайда 3:4 | 3:2, минимум 2160x1440 |
| Слайдов в карусели | до 20 |
| Длина видео-слайда | 4-6 секунд рабочих, лимит 60 |
| Минимальная ширина | 1080, иначе Instagram тянет и мылит |

Instagram обрезает **все слайды по первому**. Один слайд с чужим соотношением портит комплект целиком - поэтому `check` перед каждой загрузкой.

## Звук

В карусели звучит только активный слайд. Озвучивать все семь - получить кашу из
обрывков при листании. Звук ставится **на первый слайд**, остальные молчат.

Музыки в библиотеке нет, есть эффекты. Киберпанк-дорожка собирается из них:

```bash
python3 tools/ambience.py робот10.json -o слайд1.wav
ffmpeg -i слайд.mp4 -i слайд1.wav -c:v copy -c:a aac -b:a 192k -shortest готово.mp4
```

Роботный набор, который лёг на киберпанк-аватар: `glitch` на включении,
`impact-bass` на вес кадра, `key-press` под сервопривод, `ping` под скан,
`typing` под обработку данных, `error` под сигнал системы.

## 3D: текст за персонажем

Заголовок уходит ЗА персонажа, плашки остаются поверх. Маска считается
покадрово, поэтому движение персонажа эффект не ломает:

```bash
python3 tools/occlude.py видео.mp4 зад.png --front перед.png --contact 0.35 -o слайд.mp4
```

**Мера критична.** Мерить надо по последней строке, а не по всему блоку: при
16% площади блока за персонажем слово уже не прочитать. Рабочая зона - 3-5% по
блоку, около 15% по последней строке.

**Дыры силуэта заливаются обязательно.** Тёмные очки и одежда на чёрном фоне в
маску по яркости не попадают, и буквы просвечивают сквозь персонажа.

**Когда окклюзию НЕ брать.** Порог по яркости оставляет по контуру светлый
ореол, и на светлых участках кадра он читается как неаккуратная обрезка.
Проверено 18.08.2026 на первом слайде: глубина есть, но края бликуют. Пока нет
настоящего matting, надёжнее простая схема - **видео на заднем плане, статичный
текст целиком поверх**:

```bash
python3 tools/slide.py текст.json --overlay -o текст.png
ffmpeg -i фон.mp4 -i текст.png -filter_complex overlay -c:v libx264 -crf 17 слайд.mp4
```

Текст при этом сажается выше самой высокой точки персонажа **за весь ролик**, а
не за один кадр: голова двигается, и кромка гуляет.

## Где живут рабочие файлы

`карусели/<дата>-<слаг>/` - одна папка на карусель, рядом с исходниками.
В Загрузках файлы теряются среди скачанного.

```
01_слайд.mp4 … 07_слайд.png   готовое, в порядке публикации
планы/                        JSON вёрстки: правится текст
исходники/                    фон, оживление из модели, звук
КАК_ПЕРЕСОБРАТЬ.md            рецепт на случай правки через месяц
```

Пути к картинкам внутри плана - относительно самого плана, поэтому папка
переезжает целиком и ничего не ломается.
