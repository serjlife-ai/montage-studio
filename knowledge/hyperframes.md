## Установка и восстановление

Скиллы вендорные, в git не лежат (21 МБ + симлинки против правила 1).
В репозитории только `skills-lock.json` с хешами. Восстановление одной командой:

```bash
GIT_LFS_SKIP_SMUDGE=1 npx skills add heygen-com/hyperframes --all --full-depth
```

Ставится в корень Империи: `.agents/skills/` + симлинки в `.claude/skills/`.
Проверка движка: `npx hyperframes doctor`.

## Как встраивается в контур

Два движка, разделение жёсткое:

1. **ffmpeg-контур** (`tools/reels.py`) - работа с реальной съёмкой: резать паузы,
   выравнивать уровни, склеивать, считать инварианты.
2. **HyperFrames** - работа поверх: графика, кинетические титры, плашки, моушн.

**Порядок нельзя менять.** Сначала режем, потом одеваем - иначе графика
переделывается после каждой правки монтажа.

Точка входа всегда одна: скилл `hyperframes`. Он сам подберёт воркфлоу.
Дёргать подскиллы напрямую не надо.

## Что из 26 скиллов реально наше

| Скилл | Наш кейс |
|---|---|
| `embedded-captions` | титры за силуэтом говорящего, матирование локально |
| `talking-head-recut` | плашки и выноски на говорящую голову - формат скетчей Сержа |
| `motion-graphics` | кинетическая типографика, счётчики, лого-стинги |
| `hyperframes-audio` | сведение, «voiceover carve» - музыка расступается под голосом |
| `media-use` | подложки, SFX, LUT, TTS, удаление фона |
| `motion-doctrine` + `cut-the-curve` + `seam-craft` | законы склейки: ролик как один проезд камеры |
| `faceless-explainer` | экспертный контент без съёмки |
| `remotion-to-hyperframes` | перенос готовых композиций Remotion, если они у тебя уже есть |

Остальные - под чужие задачи (Figma, PR-видео, слайд-деки), лежат без вреда.

---

## Что HyperFrames НЕ делает

- Не считает уровни звука и не решает, где пауза. Это ffmpeg-контур и его инварианты.
- Не заменяет резку по смыслу.
- Не отменяет правило сдачи с числами.

---

## Про Remotion

В посте предлагали ставить и Remotion. Ставить второй движок того же назначения
незачем: HyperFrames закрывает те же задачи и **везёт скилл переноса**
(`remotion-to-hyperframes`). Если у тебя уже есть готовые композиции на
Remotion - портируй их, а не поднимай параллельный стек.
