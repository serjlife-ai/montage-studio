# Что монтажёр умеет и чего не умеет

> Обновлено 17.08.2026 после установки HyperFrames. Проверено на этой машине,
> а не взято из документации. Часть вчерашних ограничений снялась.

---

## Два движка, не один

У монтажёра теперь две руки, и они для разного. Путать их - главная ошибка.

| | **ffmpeg-контур** (`tools/reels.py`) | **HyperFrames** (`.agents/skills/`) |
|---|---|---|
| Что делает | режет, выравнивает, склеивает реальную съёмку | рисует поверх и вокруг: графика, анимация, титры |
| Язык | Python + фильтры ffmpeg | HTML + CSS-анимация, рендер в MP4 |
| Сильная сторона | точность по кадру и по децибелу, инварианты | дизайн, движение, кинематографичность |
| Слабая сторона | рисовать не умеет, титры плоские | не считает уровни звука и не решает, где пауза |
| Когда брать | сырой материал -> чистый монтаж | чистый монтаж -> упакованный ролик |

**Порядок работы:** сначала ffmpeg-контур режет и чистит, потом HyperFrames
одевает. Наоборот - переделывать графику после каждой правки монтажа.

Точка входа в HyperFrames всегда одна - скилл `hyperframes`, он сам выбирает
нужный воркфлоу. Вручную дёргать подскиллы не надо.

## Умею через HyperFrames (движок проверен, `doctor` зелёный)

Всё локально: ни облака, ни ключей, ни лимитов.

| Умение | Скилл | Что это даёт |
|---|---|---|
| **Титры за спиной говорящего** | `embedded-captions` | вырезает силуэт и пускает текст ПОЗАДИ человека - тот самый кинематографичный слой. Включает матирование субъекта локально |
| **Графические плашки на говорящую голову** | `talking-head-recut` | кинетические заголовки, нижние трети, выноски с цифрами, цитаты, боковые панели, картинка-в-картинке, синхронно с транскриптом |
| **Моушн-графика** | `motion-graphics` | кинетическая типографика, счётчики, графики, лого-стинги, оверлеи с прозрачностью |
| **Саунд-дизайн и сведение** | `hyperframes-audio` | «voiceover carve» - музыка сама расступается под голосом; EQ, компрессор, лимитер, гейт, реверб, автоматизация громкости |
| **Поиск и генерация медиа** | `media-use` | подложки, SFX, иконки, логотипы, LUT и цветокор, TTS-голоса, удаление фона. Всё замораживается в локальные файлы |
| **Законы движения** | `motion-doctrine`, `cut-the-curve`, `seam-craft` | склейки, которые читаются как один непрерывный проезд камеры, а не стопка слайдов |
| **Анимация и кейфреймы** | `hyperframes-animation`, `hyperframes-keyframes` | GSAP, Lottie, Three.js, маски, морфинг SVG, 3D-глубина |
| **Видео из статьи или темы** | `faceless-explainer` | экспертный контент без съёмки |
| **Видео под музыку** | `music-to-video` | нарезка по битам |
| **Промо продукта из ссылки** | `product-launch-video` | лендинг -> промо-ролик |
| **Порт старого Remotion** | `remotion-to-hyperframes` | перенос готовых композиций Remotion в HyperFrames |

## Умею через ffmpeg, но в бою не применял

| Умение | Чем |
|---|---|
| B-roll вставками и картинкой-в-картинке | `concat`, `xfade`, `overlay` |
| Привязка вставок к словам | word-таймкоды из whisper: «на слове *нейросеть* показать X» автоматизируется целиком |
| Ducking музыки под голос | `sidechaincompress` (либо `hyperframes-audio`, там это тоньше) |
| Переходы, слоумо, ускорение | `xfade`, `setpts`, `atempo`, `minterpolate` |
| Цветокор, хромакей | `eq`, `curves`, `chromakey`, `despill` |
| Три версии хука на сравнение | нарезка первых 3 секунд |

### Откуда брать b-roll

1. **Генерация.** Higgsfield MCP: `generate_video` (Seedance, Veo, Kling),
   `generate_image`, `generate_audio`.
2. **Рисование.** HyperFrames: если тема абстрактная (нейросети, деньги, рост),
   графика честнее стокового кадра.
3. **Свои файлы и скринкасты.** ffmpeg умеет захват экрана через avfoundation.
4. **Сток - нет.** Лицензионного доступа нет, качать со стоков не буду.

## Не умею на этой машине

| Чего нет | Последствие | Чем лечится |
|---|---|---|
| Kokoro TTS локально | нет офлайн-озвучки | `pip install kokoro-onnx soundfile`, либо TTS через Higgsfield |
| MusicGen локально | нет офлайн-генерации музыки | **ставить не будем**: тянет torch, а на Маке 16 ГБ - см. правило «без локальных LLM на Маке». Музыка через Higgsfield |
| OpenCV / mediapipe | нет трекинга лица для авто-реframe за говорящим | `pip install opencv-python`. Матирование субъекта для титров закрыто скиллом `embedded-captions` |
| `libass` в ffmpeg | плоские титры рисую в PIL | не мешает: кинематографичные титры теперь делает HyperFrames |
| `vidstab` | сильную тряску не вылечу | пересборка ffmpeg |
| Docker | нет контейнерного рендера | не нужен, локальный рендер работает |

## Не умею в принципе

Здесь решает Серж, и никакой движок это не закроет.

- **Не слышу звук и не смотрю видео.** Сужу по числам и по вытащенным кадрам.
  Смешно, попадает ли ритм, живая ли энергия - не мой суд.
- **Не выбираю, что резать по смыслу.** Могу разложить транскрипт и предложить
  схему, но выбрасывать содержание сам не буду.
- **Не добавляю трендовое аудио Instagram.** Оно накладывается только в приложении.
- **Не публикую.** Отдаю файл.
