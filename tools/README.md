# Инструменты монтажа

Требуют: `ffmpeg`, `whisper-cli`, `python3` с `numpy` и `Pillow`.
Модель whisper ищется сама: переменная `WHISPER_MODEL`, затем `../models/`,
затем прежние места на машине. Шрифт титров тоже ищется сам, на Linux -
через `fc-match`.

---

## `preflight.py` - предполётная проверка исходника

**Запускать первым, до любой резки.** Меряет файл и говорит, что с ним
делать: реальный кадр с учётом поворота, шумовую полку, авто-порог, разброс
громкости между фразами, запас настоящей тишины.

```bash
python3 preflight.py вход.mov --json отчёт.json --frames кадры/
./preflight вход.mov          # то же через обёртку из корня пакета
```

Что ловит:

| Находка | Почему это важно |
|---|---|
| Разброс громкости между фразами ≥ 12 dB | в файле два источника звука. Константный порог вырежет тихого |
| Тишины меньше 5% | резать паузы бессмысленно, нужна динамика катами |
| Кадр не 1080x1920 | горизонталь кропнется по середине, говорящий может уехать за край |
| Кадры полосы титров | **смотреть глазами**: если титры в исходнике уже выжжены, наши лягут вторым слоем |

Про разброс по фразам: мерить громкость по кадрам 20 мс бесполезно, речь
двугорбая сама по себе, и один говорящий даёт те же 17 dB, что и два
источника. Замером проверены и перцентили кадров, и критерий Оцу - не
разделяют. Разделяет только счёт по фразам: один голос 6-9 dB, два
источника 12-29 dB.

## `checkpoint.py` - работа не теряется при обрыве

Ролик собирается за несколько заходов, а сессия обрывается. Чекпоинт
держит состояние на диске: стадии `preflight → cut → subs → render`,
каждая пишет свой JSON.

```bash
python3 checkpoint.py init ~/монтаж/проекты/ролик --src исходник.mov
python3 checkpoint.py status ~/монтаж/проекты/ролик
python3 checkpoint.py reset ~/монтаж/проекты/ролик --stage cut
```

Из кода:

```python
p = Project("~/монтаж/проекты/ролик", src="исходник.mov")
p.save("cut", {"threshold_db": -44, "keeps": [...]})
данные = p.load("cut")     # None, если стадии ещё не было
p.done("cut")
```

Сторожит и закон «исходники не трогаем»: если файл-исходник изменился с
начала работы, `status` говорит ТРЕВОГА.

## `staticscore.py` - оценка статичности числом

Перед сдачей: не вышла ли говорящая голова без единого события в кадре.
Четыре оси по 0-5, меньше - живее.

```bash
python3 staticscore.py готово.mp4 --json оценка.json
```

| Ось | Что меряет |
|---|---|
| `cuts_rate` | склеек в минуту |
| `frame_change` | средняя разница соседних кадров |
| `longest_static` | самый долгий кусок без изменений |
| `audio_flat` | разброс громкости по фразам |

Замерено: живая съёмка 1.6, смонтированный ролик 1.0, неподвижный кадр с
речью 4.1. Вердикт от 2.5 - переделать, от 3.5 - не публиковать.

Инструмент **не решает**, смешно ли и попадает ли ритм - это зона автора.
Он ловит только механическую неподвижность, которую видно числом.

## `takes.py` - последний дубль из записи с запинками

Серж пишет врезки подряд, одну фразу может проговорить трижды: сбился,
начал заново, ещё раз. Инструмент находит повторы и предлагает последний
вариант каждой фразы.

```bash
python3 takes.py врезки.mp4 --json дубли.json
./takes врезки.mp4 --apply -o чистовик.mp4
```

Повторы ищутся **по словам, а не по звуку**: тексты нормализуются
(убираются паразиты «ну», «вот», «типа», регистр, пунктуация) и
сравниваются как последовательности слов. Замерено на текстах:
точный повтор и повтор с запинкой дают 1.00, «повтор + продолжение»
0.75-0.89, разные фразы 0.00-0.50. Порог 0.62 проходит между ними.

`--apply` сразу собирает чистовик. Без него - только план и разбор,
решение за автором: последний дубль по порядку не всегда лучший по подаче.

**Известная дыра.** Инструмент сравнивает фразы, а фразы даёт whisper.
Если человек перезашёл на фразу без паузы, whisper склеивает повтор
в одну фразу - сравнивать становится нечего, и дубль не находится.
Поймано 01.09.2026 на финале ролика-реакции: «выложил кучу всяких
классных...» → «выложил кучу полезных скиллов» инструмент не увидел,
дубль нашёлся прослушиванием кусков по 8 с. Перед сдачей длинной врезки
распознать её целиком и прочитать текст глазами.

## `whisper_json.py` - чтение выдачи whisper

Не инструмент, а общий загрузчик: им читают JSON от `whisper-cli` все
остальные (`dynamic`, `subtitles`, `reels`, `reel`, `takes`).

При разборе по словам (`-ml 1`) whisper режет вывод на токены и рвёт
русскую букву пополам на границе: кириллица занимает два байта, а
токен обрывается между ними. В файле остаётся невалидный UTF-8, и
обычный `json.load` падает с `UnicodeDecodeError` посреди готовой работы.

Загрузчик выбрасывает битые байты и печатает, сколько их было.
На реальных файлах - 2 байта на файл.

```python
from whisper_json import load_whisper_json
data = load_whisper_json("w.json")
```

## `interject.py` - сборка ролика-реакции

Чужое видео + свои врезки + ускорение скучных кусков. Жанр и его законы -
[../knowledge/comedy-reaction.md](../knowledge/comedy-reaction.md).

```bash
./interject план.json --check          только проверить план
./interject план.json -o ролик.mp4     собрать
```

План:

```json
{
  "donor": "донор.mp4",
  "cuts": [
    {"at": 12.4, "file": "panch1.MOV", "take": [3.1, 4.6], "type": "панч"},
    {"at": 37.4, "file": "reakciya.MOV", "take": [0.6, 3.4], "react": true},
    {"speed": [45.0, 58.0], "factor": 2.0}
  ]
}
```

Три типа кусков:

| Тип | Что происходит | Когда |
|---|---|---|
| говорящая врезка | донор замирает, звучит твой панч, потом донор продолжает с того же места | ты что-то говоришь |
| **немая реакция** (`"react": true`) | видеоряд переключается на твоё лицо, **речь донора идёт непрерывно** | ты молча офигеваешь под чужой текст |
| ускорение | кусок донора гонится быстрее с сохранением высоты голоса | «зайди сюда, нажми туда» |

Немая реакция - отдельный приём, не частный случай врезки. Если вставить
лицо обычной врезкой, фраза донора рвётся пополам и шутка ломается.
Здесь кусок донора под реакцией «съедается»: зритель слышит блогера и
видит, как ты от этого офигеваешь. Паузы перед такой врезкой нет -
речь не должна прерываться.

Что делает сам:

- держит **паузу 0.3 с перед каждой говорящей врезкой** замершим кадром донора.
  Без паузы врезка звучит как перебивание, а не как панч;
- ускоряет помеченные куски через `atempo` (не `setpts` на звуке -
  иначе речь становится бурундуком);
- сводит уровни: донор -16 LUFS, врезка -13 LUFS, плюс затухание донора
  за 0.15 с до врезки.

**Валидатор роняет сборку** на битом плане: врезка вне длины файла,
ускорение выше 2.5х, пересекающиеся ускорения. Отдельно предупреждает,
если врезок в первой половине больше, чем во второй - это нарушение
закона жанра о росте плотности к финалу.

В конце считает долю своего материала. Меньше 25% - предупреждение:
площадки считают такое перезаливом чужого, а не пародией.

## `clips.py` - нарезка эфира на самодостаточные клипы

Из одного длинного исходника - N независимых коротких роликов.
**Инструмент не режет сам**: читает транскрипт, считает по каждому куску
измеримые признаки и выдаёт ранжированные предложения с таймкодами.
Что брать - решает автор.

```bash
python3 clips.py транскрипт.srt --count 5 --min 25 --max 75
./clips эфир.srt --source эфир.mp4 --json клипы.json
```

Принимает SRT или JSON от `whisper-cli -oj`. Режет только по границам
предложений: клип, начатый с середины мысли, вне эфира не читается.

| Ось | Что ловит |
|---|---|
| вход | начало со связки («и вот», «это», «поэтому») - без предыдущей фразы непонятно |
| финал | обрыв на середине мысли |
| контекст | отсылки к эфиру: «как я говорил», «в прошлом видео» |
| визуал | привязка к картинке: «вот здесь», «на экране» - нужен исходный кадр |
| темп | слов в секунду: вялый кусок не удержит |
| хук | вопрос, цифра или обещание в первых секундах |

С `--source` печатает готовые команды ffmpeg для каждого клипа.

## `reels.py` - полный цикл

Резка пауз → выравнивание уровней → титры → отчёт с проверками.

```bash
python3 reels.py вход.mov -o выход.mp4 --censor
```

| Флаг | Что делает |
|---|---|
| `-o` | путь результата (по умолчанию `<вход>_reels.mp4`) |
| `--censor` | мат в титрах за звёздочками |
| `--analyze` | только отчёт по уровням и катам, без рендера |
| `--threshold -46` | порог тишины вручную вместо авто |
| `--no-level` | не выравнивать громкость говорящих |
| `--no-subs` | без титров |
| `--lang en` | язык распознавания |

Отчёт на выходе:

```
шумовая полка -66 dB | громкая речь -27 dB | порог -46 dB (авто)
катов: 25  вырезано: 28.5s  итог: 2:59.0 из 3:27.4
инвариант: громчайший вырезанный кадр -47 dB (порог -46)
слов: исходник 446 -> итог 444 | титры: 144 фраз
```

Читать так: порог подобран сам, речь не пострадала (вырезанный максимум ниже
порога), слов потеряно 2 из 446 - это разброс распознавания, а не резка.

**Начинать с `--analyze`.** Он быстрый и сразу показывает, сколько в файле
настоящей тишины. Если её мало - резка пауз ролик не спасёт, нужна резка по смыслу.

## `subtitles.py` - только титры

Если видео уже смонтировано и нужны титры поверх.

```bash
python3 subtitles.py видео.mp4 слова.json выход.mp4 --censor
```

`слова.json` - выдача `whisper-cli -ml 1 -oj`. Модуль импортируется из `reels.py`,
но работает и сам по себе.

Настройки стиля - константы в начале файла: `BAND_Y` (высота полосы), `SIZE`,
`ACCENT` (цвет активного слова), `MAX_WORDS`, `SWEAR_ROOTS`.

## Входная проверка

Кадр меряется с учётом матрицы поворота (iPhone пишет вертикаль как 1920x1080
+ rotation -90). Если реальный кадр не 1080x1920, сборка не стартует и печатает
готовую команду перегона: молчаливый кроп чужого материала хуже отказа.

---

## Инварианты, которые роняют сборку

Оба поставлены после реальных дефектов, снимать нельзя.

1. **Порог.** Самый громкий кадр внутри вырезаемого куска обязан быть тише порога.
   Иначе под нож попала речь → `AssertionError`.
2. **Верстка.** Каждая фраза титров обязана влезть в кадр и в полосу.
   Иначе текст уедет за край → `AssertionError`.

Обоснование: [[../knowledge/audio-two-sources]].

## `dynamic.py` - каты с зумом, когда резать нечего

Для материала, снятого без пауз. Динамика из ритма кадрирования и звука.

```bash
python3 dynamic.py вход.mov -o выход.mp4
```

| Флаг | Что делает |
|---|---|
| `--plan` | только план катов, без рендера |
| `--words` | готовый words.json (иначе транскрибирует сам) |
| `--no-sfx` | без свушей и попов |
| `--sfx-dir` | другой банк звуков |

Отчёт: число планов, средняя длина, свушей/попов/кликов, итоговое усиление.
Два инварианта: план не короче 0.75 с и не длиннее 2.6 с.

**Начинать с `reels.py --analyze`.** Если тишины меньше 5% хронометража,
резать нечего - работает `dynamic.py`. Обоснование: [[../knowledge/dynamic-cuts]].

## `accents.py` - смысловые акценты

Число-шильдик и карточка призыва в верхней зоне кадра.

```bash
python3 accents.py вход.mp4 акценты.json выход.mp4
```

```json
[{"type":"chip","text":"50 000 ₽","sub":"ЗАРПЛАТА В МЕСЯЦ","start":28.05,"end":30.4},
 {"type":"cta","text":"МОНТАЖ","sub":"НАПИШИ В КОММЕНТАРИЯХ","start":32.3,"end":34.9}]
```

Три инварианта: полоса акцентов не налезает на титры, плашка влезает в кадр,
ни один символ не рисуется квадратом (в Arial Black нет рубля - проверено).

## `window.py` - голова в окошко, место под презентацию

```bash
python3 window.py вход.mp4 окна.json выход.mp4
# окна.json: [{"start": 6.58, "end": 10.38}, {"start": 16.9, "end": 22.3}]
```

Меняет только геометрию: в указанных кусках кадр уезжает в окно 520x924, снизу
освобождается площадь под текст. Текст туда кладёт `creative.py` типами
`winframe` и `panel`.

**В оконных кусках титры обязательно гасить:**

```bash
python3 subtitles.py win.mp4 слова.json cap.mp4 --censor --mute 6.5-10.45,16.85-22.35
```

Иначе фраза, начавшаяся до окна, повиснет поверх презентации.

Инварианты: окна не пересекаются, каждое не короче 0.3 с, не выходят за длину
ролика, презентация влезает по высоте.

## `carousel.py` - динамичная карусель Instagram

Не про ролики. Про пост-карусель, где слайд оживает: картинка двигается, текст
стоит. Канон и промпты - [../knowledge/dynamic-carousel.md](../knowledge/dynamic-carousel.md).

Нарезать широкий макет на бесшовные слайды (шов пиксель в пиксель):

```bash
python3 carousel.py slice панорама.png --slides 2
```

| Флаг | Что делает |
|---|---|
| `--slides 2` | на сколько слайдов резать |
| `--ratio 3:4` | соотношение одного слайда (или `4:5`) |
| `--width 1080` | ширина одного слайда в пикселях |
| `-o` | куда класть слайды |

Работает и с картинкой, и с видео - кроп один и тот же, так что оживлённая
панорама режется тем же способом, что и статичная.

Проверить комплект перед загрузкой:

```bash
python3 carousel.py check слайд1.png слайд2.mp4 слайд3.png
```

Ловит разъезд соотношений (Instagram режет ВСЕ слайды по первому), выход за
лимиты ленты, ширину меньше 1080, видео длиннее 60 секунд. Выход 1 - не грузить.

## `slide.py` - верстка слайда карусели

Второй слой закона двух слоёв: нейросеть даёт визуал, буквы ставит этот
инструмент. Кириллица не плывёт, правка текста не требует перегенерации.

```bash
python3 slide.py слайд1.json -o слайд1.png
python3 slide.py --format          # формат плана
```

План описывает холст, фото и слои. Типы слоёв: `text` (многострочный
заголовок), `arrow` (горизонтальная стрелка), `badge` (кружок со стрелкой и
подпись). Пути к картинкам - относительно самого плана, чтобы план переезжал
целиком.

Шрифт берётся первым найденным из списка, переопределяется `SLIDE_FONT`.

**Инвариант:** любой элемент, вылезающий за safe zone (94% кадра), роняет
сборку с кодом 1. Интерфейс Instagram ест края, и текст в них теряется.

### Текст поверх видео

Если слайд оживляется, текст нельзя запекать в картинку до оживления - модель
его испортит. Порядок:

```bash
python3 slide.py база.json -o база.png        # план без layers: только фото
# база.png уходит в image-to-video, возвращается база.mp4
python3 slide.py слайд1.json --overlay -o текст.png
ffmpeg -i база.mp4 -i текст.png -filter_complex overlay -c:a copy слайд1.mp4
```

`--overlay` рисует только слои на прозрачном фоне. Проверено: наложение даёт
тот же кадр, что и прямая сборка, среднее расхождение меньше 1 из 255
(разница только в сглаживании краёв букв).

### Зацикливание видео-слайда

```bash
python3 carousel.py loop база.mp4 -o слайд1_цикл.mp4
python3 carousel.py loop база.mp4 --mode crossfade --fade 0.8 -o слайд1_цикл.mp4
```

`pingpong` (по умолчанию) - прямой ход и обратный без крайних кадров, стык
гладкий всегда, длина удваивается. `crossfade` - хвост растворяется в начало,
длина уменьшается на время растворения; берётся для направленного движения,
которое в реверсе выглядит неестественно.

Инструмент меряет разрыв между последним и первым кадром до и после и говорит,
если стало хуже. На проверке: разрыв 125.1 из 255 стал 0.6 у пинг-понга и 5.2
у растворения.

## `ambience.py` - саунд-дизайн слайда

Не музыка и не синтез: готовые эффекты из библиотеки media-use
(Pixabay Content License) расставляются по таймлайну.

```bash
python3 ambience.py звук5.json -o слайд1.wav
python3 ambience.py --list x -o x        # список доступных звуков
```

План: `{"duration": 5.0, "cues": [{"sound": "glitch-1", "at": 0.0, "gain_db": -13}]}`

**Инварианты:** доля энергии выше 6 кГц больше 30% роняет сборку (тот самый
дефект, что завалил синтез свушей); хвост, не ушедший в тишину, роняет тоже -
на зацикленном слайде обрыв слышен как щелчок. Проверено: дорожка из звонких
звуков падает на 33.8%.

Хвост всегда уводится в тишину за 0.25с, старт - за 0.01с.

## `occlude.py` - 3D: текст уходит ЗА персонажа

Даёт объём вместо плоской плашки поверх кадра. Маска переднего плана считается
**покадрово**, поэтому персонаж может двигаться - поворот головы эффект не ломает.

```bash
python3 slide.py зад.json  --overlay -o зад.png     # заголовок, уйдёт за персонажа
python3 slide.py перед.json --overlay -o перед.png  # плашки, останутся поверх
python3 occlude.py видео.mp4 зад.png --front перед.png --contact 0.35 -o слайд.mp4
```

| Флаг | Что делает |
|---|---|
| `--front` | слой, который всегда поверх: плашки, призыв, номер слайда |
| `--threshold` | порог отделения от тёмного фона (по умолчанию 10) |
| `--grow` | ядро чистки тонких линий фона, нечётное (9) |
| `--feather` | мягкость края маски (1.2) |
| `--contact` | контактная тень: буквы темнеют у силуэта, 0..1 |

Дыры внутри силуэта (тёмные очки, одежда на чёрном фоне) заливаются, иначе
буквы просвечивают сквозь персонажа.

Инструмент печатает разброс перекрытия по кадрам и предупреждает, если оно
превысило 35% - там слово перестаёт читаться. Рабочая зона 3-5% по всему блоку
текста, что даёт около 15% по последней строке.

Скорость: примерно 1.2 с на кадр в 1080x1440.

### Слои для слайдов с контентом

К `text`, `arrow`, `badge` добавлены:

| Слой | Что рисует |
|---|---|
| `pill` | скруглённая плашка-ярлык: «ШАГ №1 И ПРОМПТ» |
| `panel` | полупрозрачная панель с неоновой обводкой под текст промпта |
| `body` | абзацы мелким текстом с автопереносом по ширине |
| `bookmark` | иконка закладки и подпись «СОХРАНИ, ЧТОБЫ НЕ ПОТЕРЯТЬ» |

В любом слое можно задать `"font": "black" | "bold" | "regular"` или путь к файлу:
заголовкам жирное начертание, абзацам обычное, иначе полотно текста нечитаемо.

У фото появился `"dim": 0.62` - персонаж уходит в тень, центр отдаётся тексту.
